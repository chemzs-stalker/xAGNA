# xagna

The full xAGNA NPC animation overhaul (Anomaly / GAMMA), with the reworked script layer.

The scripts are additive and never replace a vanilla file.

- `gamedata/scripts/`: `xagna_core`, `xagna_mcm`, `zzz_xagna_overrides`
- `gamedata/meshes/`: the OMF animations
- `gamedata/configs/`: the DLTX
- `gamedata/textures/`: the textures
- `doc/architecture.md`: how it works
- `doc/changelog`: version history

The repo holds the complete mod, ready to install.

## Compatibility

Additive and safe on any Anomaly or GAMMA install: it replaces no vanilla file and coexists with other NPC animation mods.

With the latest demonized exes, each relaxed NPC holds its own standing idle pose. On older builds that one touch stays off and nothing else changes.
